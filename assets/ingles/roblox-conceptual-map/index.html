Structure

Explorer & Properties

Think of Explorer as a file tree for 3D. The parent owns the children; moving a Model moves everything inside. Properties shows tunable values: Size, Position, Color, Transparency, Anchored, CanCollide, Material.

game
├─ Workspace — world
├─ ReplicatedStorage — shared
├─ ServerScriptService — server code
└─ StarterGui — UI
2 / 14

Code

Luau Scripting

Luau is Roblox's fast, gradually-typed Lua. Use Script (server), LocalScript (client), ModuleScript (shared library) and react to events like .Touched or .Changed.

-- ModuleScript in ReplicatedStorage
local Coins = {}
function Coins.add(player, amount)
  player.leaderstats.Coins.Value += amount
end
return Coins

Vocabulary: Type checking — verificación de tipos; Event — evento.

Parts & Models

A Part is a primitive shape. Model groups parts with a PrimaryPart for pivoting. MeshPart imports Blender models. Master Anchored (fixed in world) vs unanchored (physics).

Assets

Toolbox & Marketplace

Speed up creation with free models, meshes, images, audio and plugins. Creator Marketplace checks legality and quality — but always inspect scripts for viruses.

Pro tip: prefer "By Roblox" verified models. Search filter: "Include only verified creators".

Feedback

Sound & VFX

Sound objects play audio (SoundId = rbxassetid://). ParticleEmitters spawn sparks, smoke, magic. Beams and Trails visualize motion.

local s = Instance.new("Sound")

8 / 14

Simulation

Physics & Animation

Roblox physics runs at 240 Hz. Use Constraints instead of legacy joints: Hinge for doors, Prismatic for elevators, WeldConstraint for rigid attach. Animate with Rig + Animator + Animation.

9 / 14

Networking

Events & Communication

Clients cannot trust each other. RemoteEvent:FireServer() must be validated on server. Prefer UnreliableRemoteEvent for frequent visual updates to save bandwidth.

RemoteEvent

One-way, fast

RemoteFunction

Request + wait response

10 / 14

Persistence

DataStore & Persistence

DataStoreService:GetDataStore() gives a key-value DB. Use auto-save on PlayerRemoving + BindToClose. Throttle limits apply — bundle data!

game:BindToClose(function()
  for _,plr in pairs(Players:GetPlayers()) do save(plr) end
end)
11 / 14

Business

Monetization

Game Pass = lifetime unlock (VIP). Developer Product = consumable (coins). Verify with MarketplaceService:UserOwnsGamePassAsync() and handle ProcessReceipt.

Identity

Avatar & Catalog

Humanoid defines health, walk speed, rig type (R6/R15). Avatar Editor + Catalog let players express identity; your game can reward UGC.
