Studio

Roblox Studio

What is it?

Roblox Studio is the free editor to create games. You can build the world, add models and test the game before publishing. It includes the Explorer to see all objects and the Properties panel to edit them.

In Spanish: Roblox Studio es el editor gratuito para crear juegos. Puedes construir el mundo, añadir modelos y probar el juego antes de publicarlo.

World

Workspace

What is it?

The Workspace is the 3D world where the game happens. It contains the terrain, lighting and all visible objects. You can change the sky, add hills and adjust gravity here.

In Spanish: El Workspace es el mundo 3D donde ocurre el juego. Contiene el terreno, la iluminación y todos los objetos visibles.

Building

Parts & Models

What is it?

Parts are the basic building blocks: blocks, spheres and wedges. A Model groups many parts together. MeshParts import custom shapes. You can change their material, color and size.

In Spanish: Las Parts son los bloques básicos: cubos, esferas y cuñas. Un Model agrupa muchas partes. Puedes cambiar su material y color.

Character

Avatar

What is it?

The Avatar is the player character. It uses a Humanoid to walk, jump and have health. You can add accessories, clothes and change its rig and animations.

In Spanish: El Avatar es el personaje del jugador. Usa un Humanoid para caminar y saltar. Puedes añadir accesorios y cambiar su apariencia.

Interface

User Interface

What is it?

The User Interface is what the player sees on screen: menus, buttons and text. It is created in StarterGui with ScreenGuis, Frames and Labels.

In Spanish: La Interfaz de Usuario es lo que el jugador ve en pantalla: menús, botones y texto. Se crea en StarterGui.

Economy

Monetization

What is it?

Monetization lets players support the game with Robux. A Game Pass is bought once, a Developer Product can be bought many times. It helps creators earn from their work.

In Spanish: La monetización permite a los jugadores apoyar el juego con Robux. Un Game Pass se compra una vez, un Developer Product varias veces.

Share

Publish & Play

What is it?

Publishing shares your game with others. Players can play on mobile, PC or console. You can update the game anytime and see how many people play.

In Spanish: Publicar comparte tu juego con otros. Los jugadores pueden jugar en móvil, PC o consola.
