Platform

Roblox Studio

Studio is a free IDE where you assemble the Data Model (ReplicatedStorage, Workspace, ServerScriptService, StarterGui, etc.), edit Properties and run Play Solo to debug.

Key vocabulary

  • Data Model — Modelo de datos
  • Explorer — Explorador
  • Output — Consola de salida

Try in Studio

View → Explorer
View → Properties
Test → Play

Structure

Explorer & Properties

Think of Explorer as a file tree for 3D. The parent owns the children; moving a Model moves everything inside. Properties shows tunable values: Size, Position, Color, Transparency, Anchored, CanCollide, Material.

game
├─ Workspace — world
├─ ReplicatedStorage — shared
├─ ServerScriptService — server code
└─ StarterGui — UI

Code

Luau Scripting

Luau is Roblox's fast, gradually-typed Lua. Use Script (server), LocalScript (client), ModuleScript (shared library) and react to events like .Touched.

-- ModuleScript in ReplicatedStorage
local Coins = {}
function Coins.add(player, amount)
  player.leaderstats.Coins.Value += amount
end
return Coins

Assets

Toolbox & Marketplace

Speed up creation with free models, meshes, images, audio and plugins. Always inspect scripts for viruses.

Interface

UI System (StarterGui)

All UI lives in StarterGui and is cloned to each PlayerGui. Use AnchorPoint + Size {Scale, Offset} for responsive layouts.

└─ Frame (UIPadding, UICorner)
├─ TextLabel — “Score: 100”

Feedback

Sound & VFX

Sound objects play audio (SoundId = rbxassetid://). ParticleEmitters spawn sparks, smoke, magic.

local s = Instance.new("Sound")
s.SoundId = "rbxassetid://12222030"
s.Parent = workspace

Simulation

Physics & Animation

Roblox physics runs at 240 Hz. Use Constraints instead of legacy joints: Hinge for doors, Prismatic for elevators, WeldConstraint for rigid attach.

Networking

Events & Communication

Clients cannot trust each other. RemoteEvent:FireServer() must be validated on server. Prefer UnreliableRemoteEvent for frequent visual updates.

RemoteEvent

One-way, fast

RemoteFunction

Request + wait response

Persistence

DataStore & Persistence

DataStoreService:GetDataStore() gives a key-value DB. Use auto-save on PlayerRemoving + BindToClose.

game:BindToClose(function()
  for _,plr in pairs(Players:GetPlayers()) do save(plr) end
end)

Business

Monetization

Game Pass = lifetime unlock (VIP). Developer Product = consumable (coins). Verify with MarketplaceService.

Identity

Avatar & Catalog

Humanoid defines health, walk speed, rig type (R6/R15). Avatar Editor + Catalog let players express identity.

Go Live

Publishing & Analytics

Hit File → Publish to Roblox, set age rating and description, then monitor Creator Dashboard for crashes and retention.
